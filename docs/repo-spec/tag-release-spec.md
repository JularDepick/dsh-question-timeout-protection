# Tag&Release 规范

## 版本号

遵守 `v<主版本号>.<次版本号>.<修订版本号>` 格式, 例如 `v0.1.0`.

> README 的版本徽章显示文字中, 版本号不带 `v` 字母前缀

## Tag

遵守 `<版本号>` 格式.

## Release

遵守 `<版本号>-dsh-<最佳适用的 dsh 版本号>` 格式, 例如 `v0.1.0-dsh-0.2.1-rc.1`.

> 本插件的 Release 绑定于开发插件时开发者使用的 dsh 版本(可能不是最新版), 并且同一个 Release 内不做多 dsh 版本适配. 这限制了一个 Release 只能绑定一个 dsh 版本号, 开发者想要更新 dsh 版本号就必须迭代版本号并发布新的 Release.
